# Lab Console · 实验室仪器控制台

**通用实验室仪器上位机**（测试台控制台）。当前支持 **ITECH IT6302** 三路可编程直流电源 + **IT8511A+ / IT8510** 可编程直流电子负载；架构上按"型号驱动可注册"设计，后续计划接入其他厂家的仪器。

桌面程序（原生窗口，不经过浏览器），单个 exe 双击即用。

> - 仓库：`github.com/li-wanxin/lab-console`（SSH: `git@github.com:li-wanxin/lab-console.git`）
> - 分支：日常开发都在 **`dev`** 分支，`master` 留给稳定发布
> - **开发与变更记录见 [DEVLOG.md](DEVLOG.md)**——接手前（人或 AI）请先读它了解当前进度

## 一、先说结论：GitHub 上没有能直接拿来用的成品

查过之后，现成方案分三类，都不能满足"这两台机器开箱即用"：

| 项目 | 情况 | 为什么不能直接用 |
|---|---|---|
| [loveboyme/Unified-ITECH-Control](https://github.com/loveboyme/Unified-ITECH-Control) | PyQt5 + PyVISA 的 ITECH 双设备 GUI，思路与本项目最接近 | 命令集按 **IT6000 系列 + IT8902E** 写死（`INST:NSEL`、多档位等），IT6302 / IT8511A+ 的通道语法与量程不同，需改代码 |
| [Blinkinlabs/itech_usb_serial](https://github.com/Blinkinlabs/itech_usb_serial) | Python 库，IT8511 私有 26 字节 UART 协议 | 只覆盖没有 SCPI 的老机型；IT8511**A+** 走标准 SCPI，用不上 |
| [mattvenn/it8512](https://github.com/mattvenn/it8512) | IT8512 私有协议小脚本 | 同上，且无界面 |
| open-EE-workbench / Open-Lab-Automation | 通用 VISA 自动化框架 | 仪器库不含 IT6302 / IT8511A+，要自己写 JSON 驱动，配置成本高于直接用 |

所以本项目的定位：**按这两台机器的实际命令集写的最小可用上位机**，命令全部对着官方编程手册核过（见第五节）。

## 二、硬件前提（很关键）

两台仪器后面板的 DB9 都是 **TTL 电平**，不是标准 RS232。**不能用普通串口线直连电脑**，会损坏仪器。

需要其中一个转换模块，插上后在系统里显示为 `COMx`：

- **IT-E121**：TTL ↔ RS232，再配一根标准直通串口线
- **IT-E122**：TTL ↔ USB，直接插 USB（更常用）

两台仪器各需要一个。IT6302 手册写明"支持 RS232/USB 通讯，使用 IT-E121 支持 RS232 通信，IT-E122 支持 USB 通信"；IT8511A+ 同属 IT8500+ 系列，手册列出 IT-E121/E121A/E122/E123 可选模块。

串口参数：**9600, 8, N, 1**（IT6302 支持 4800/9600/38400，默认 9600）。

接线：

```
IT6302 CH1 (+) ──────── IT8511A+ (+)   ← 负载吸收电源输出
IT6302 CH1 (-) ──────── IT8511A+ (-)
```

> 注意：电子负载是"吸收电流"的，不能当电源用。测试时电源输出端接负载输入端，负载设为 CC/CR/CP 拉电流。

## 三、启动

### 方式 A：直接运行打包好的程序

双击 `dist\LabConsole-Portable.exe`。**单文件、免安装**，不依赖 Python 环境，也不需要浏览器。

> ⚠️ `dist/` 里的 exe 是早期版本打包的，**界面落后于当前源码（v55）**，重新打包前请以源码运行方式为准。

第一次启动约 2–4 秒（程序要自解压到临时目录），之后正常。窗口大小按屏幕分辨率自动适配。

### 方式 B：从源码启动

```bash
git clone git@github.com:li-wanxin/lab-console.git
cd lab-console
pip install -r requirements.txt
python desktop.py            # 原生窗口
python app.py                # 浏览器模式 http://127.0.0.1:8765
```

也可以双击 `启动.bat`，会自动补装依赖。开发调试常用：`python app.py --port 8799 --no-browser`。

### 方式 C：自己重新打包

双击 `打包.bat`，或：

```bash
python -m PyInstaller --onefile --windowed --name "LabConsole-Portable" ^
  --icon app.ico --add-data "web;web" desktop.py
```

### 没有硬件也能看界面

勾选左侧 **"模拟模式"** 再点连接，两台设备会以联动模型运行（电源带 0.06Ω 输出内阻，负载按 CC/CV/CR/CP 计算电流），扫描和曲线都能跑通。可以先用它熟悉操作。

## 四、界面与功能

### 左侧导航：三张卡片，点击切换右侧整页

| 卡片 | 右侧显示 |
|---|---|
| 直流电源 IT6302 | 三通道卡片 + 三通道曲线 |
| 电子负载 IT8511A+ | 模式设定 + 读数 + 负载曲线 |
| 联动测试 | 扫描参数 + I-V 曲线（电源与负载联动） |

- 每张卡片带状态灯：灰=未连接，绿=已连接，橙=模拟中，红=通信异常
- 选电源或负载时，卡片下方的连接设置（串口、波特率、模拟模式、连接后先关断）跟着切换，两台各自记住自己的端口
- 选联动测试时，连接设置换成**两台在线状态清单**，缺哪台一眼能看出，点「去连接」直接跳到那台
- 导航卡片上还能看到扫描进度（例如 `45%` / `已完成`），切到别的页面也不会错过
- 左下角**深色 / 浅色主题**一键切换，画布配色跟随主题重绘，选择持久保存

### 电源 IT6302

- CH1/CH2 0–30V / 3A，CH3 0–5V / 3A，独立设定电压与限流
- 每通道独立开关（大号拨杆：绿色 ON / 红色 OFF 带文字），另有"全部 ON / 全部 OFF"
- 实时回读一行三值：电压（蓝）· 电流（青）· 功率（橙），竖线分隔、颜色与曲线一一对应；汇总总功率与开启路数

### 负载 IT8511A+ / IT8510

- CC / CV / CR / CP 四种模式，量程按型号：IT8511A+ 150V / 30A / 150W，IT8510 120V / 30A / 300W（两者同属 IT8500 系列，SCPI 协议命令集完全一致）
- 设定值超量程直接拒绝下发，不会打到仪器保护
- 切换模式时自动用该模式的保守默认值（CC 0.5A、CV 5V、CR 100Ω、CP 10W），避免沿用旧数值造成过流
- 实时回读 V / I / P，量程标注与设定上限随型号自动联动

### 仪器清单：多设备添加 / 删除

软件支持**任意数量的电源 / 负载同时在线**（如 1 电源 + 2 负载、2 电源 + 1 负载），每台独立连接、独立控制、独立曲线与数据表、独立记录：

- **删除**：侧栏条目悬停出现「×」，点击后变「确认删除」（两步防误删），已连接的仪器先自动断开再从清单移除，对应视图与顶栏 pill 同步消失；
- **添加**：点「＋ 添加仪器」弹对话框，选**仪器类型**（直流电源 / 电子负载）和**型号**（电源：IT6302；负载：IT8511A+ / IT8510），按添加顺序自动命名（电源 1、负载 2…）；
- 每台设备一个侧栏条目、一个独立视图；连接设置面板跟随当前选中的设备（负载可换型号后重连）；
- **联动测试**可在多台中选两台：扫描表单里有「电源设备」「负载设备」下拉，选哪两台就扫哪两台；
- **数据记录按设备独立**：每台设备的面板各有「开始记录」，互不干扰，可同时记录多台；
- 急停作用于清单内全部设备。

### 曲线：一个通道一张图，图内同表 U / I / W

每张曲线图下方有一条**原始数据表**：时间（系统时钟 HH:MM:SS）+ U/V + I/A + P/W 四列，按采集节拍（0.8s）取样、最新在最上一行，随采集实时刷新；表格区**默认正好显示 10 行**，**拖动曲线与表格之间的分隔条可调高/调低**（最多缓存 40 条，超出滚动查看，表头固定）；列与导出 CSV 一一对应。

电源和负载两个视图的曲线都是**同一张画布内竖向分条**，各条共用一根时间轴、竖格线贯通：

- **电源视图：三张图横向并排**，CH1 / CH2 / CH3 一张对一张，正对着上方的三个配置卡片；每张里同表画本通道的三个量：
- **三张图常驻**：输出未开启的通道曲线照常绘制（关闭后数值归零，历史台阶仍可回看），标题条以灰色显示"输出未开启"；数据始终采集（也进 CSV）
  - 电压 V —— 蓝色实线，左轴（刻度数字也是蓝色）
  - 电流 A —— 青色虚线，右外轴（青色数字）
  - 功率 W —— 橙色点线，右内轴（橙色数字）
- **负载视图**只有一路，同样是一段内三线三轴
- 轴的数字颜色跟曲线一致，不用看图例也能对上是哪条线
- **鼠标移到图上**出现竖直游标，各条交点同时打点，并在远离游标的一侧弹出读数框（时刻 + 每通道的 V / A / W 数值）

每条分道内部三个量纲各占一根轴、互不归一化：电压是电压的刻度、功率是功率的刻度，读数直接对轴，不需要换算。恒压时功率线和电流线形状相同是物理事实（P = V×I），但它们各自读各自的轴，不再互相盖住。

联动测试的 I-V 扫描图仍是**单段双轴**（左轴电压、右轴电流或功率），因为横轴本身就是被扫的物理量，双轴读的是同一条 I-V 曲线。

缓存 20000 点（约 4.4 小时 @0.8s），界面取最近一段时间绘制，可一键清空。绘图按像素抽样，上万点也不会拖慢刷新。

### 数据记录与导出

电源/负载视图在**通道设置下方、曲线上方**有「**开始记录**」按钮和记录条目区：

1. 点击后弹出对话框：**单路/多路**切换（单路只选一个对象，多路可任意勾选）、**记录间隔**（0.8s（最快）/ 1s / 2s / 5s / 10s / 30s / 1 分钟，记住上次选择——间隔越大数据量越小）、**存储目录**（桌面版可点「选择目录」打开系统目录选择，目录自动创建）+ 文件名；记录对象**跟随当前输出结构**——组合模式下显示「CH1+CH2 串联」「CH3」等逻辑输出，组合项按组合公式计算（串联 ΣV/取小电流，并联电压/ΣI）；
2. 确定后按钮旁出现红点「记录中」条目，显示通道、采样间隔、起始时间和已采集点数，可**同时存在多条记录**；
3. 点「结束记录」→ 按钮变「导出中…」→ CSV 完整写出后条目消失。

数据表时间列为**系统时钟**（HH:MM:SS），与实际操作时刻直接对应。

| 记录 | 内容 |
|---|---|
| 电源记录 | 时间、所选逻辑输出（单通道或组合）各电压·电流·功率，间隔 0.8s ~ 1 分钟可选 |
| 负载记录 | 时间、电压、电流、功率、当时的工作模式、设定值 |

扫描结果仍走原「导出 CSV」；CSV 带 UTF-8 BOM，Excel 双击直接打开中文不乱码。

### 通道联合输出

电源视图顶部是独立的「**单路 | 组合**」两段式按钮（单路=绿色、组合=蓝色，与下方卡片配色一致），选到「组合」后旁边出现模式下拉（接线按 IT6302 手册手动完成，软件负责联动）：

- **CH1+CH2 串联**（60V/3A）/ **CH1∥CH2 并联**（30V/6A）/ **CH1+CH3、CH2+CH3 串联**（35V/3A）
- **切换单路/组合只是换视图，不改变任何输出状态**；组合接通状态下切到单路，成员通道显示「占用」+ OFF，尝试单独开启会弹窗提示"先关闭组合输出"（可一键关闭组合并按单路开启该通道）
- **组合卡 ON 需过接线指引**：弹出接线示意图（端子竖放、跳线与负载接法）+ 成员通道实时 V/A，可逐通道手动关闭输出；确认后先关成员原有输出再开启组合
- **输出 ON 时修改电压/限流设定会先自动关闭输出**（防误触带载改压），toast 提示确认后手动重新开启
- 组合模式下界面按**实际输出路数**重排：组合卡替换成员卡（如「CH1+CH2 串联」一张卡 + CH3 一张卡），卡片与曲线/数据表同宽均分；组合卡用蓝色系、量程按组合能力显示（如 60V/3A）
- 组合卡设定自动分解：串联对半分压（s13/s23 由 30V 通道吃满、余量给 5V 通道，超 35V 拒绝）、电流各路相同；并联电压相同、电流对半
- 组合读数：串联 V=ΣV、I=取小；并联 V=取同、I=ΣI

### 联动测试（I-V 扫描）

左栏第三张卡片进去是一整页：左边扫描参数，右边曲线。

两种方式，都带进度、可随时停止、结束后自动关断（可关）：

1. **负载电流扫描（电源恒压）**——电源固定输出，负载 CC 从起始扫到终止电流，记录每点电压/电流/功率。用来测电源的负载调整率、线缆压降、接插件接触电阻。
2. **电源电压扫描（负载恒流）**——负载固定拉流，电源电压从起始扫到终止，测回路/被测件的 I-V 特性。

曲线横轴是扫描设定值（电流或电压，右上角有标注），左轴电压、右轴电流；「功率」按钮同样可以把右轴切成 W。结果可导出 CSV。

### 安全

- 右上角 **急停**：同时关电源三路输出 + 负载输入
- 软件保护：负载功率超 150W、电源单路电流超限自动脱扣（默认开启）
- 关闭窗口会先执行急停再退出，不会留输出开着

### 通信自检

连接后点"通信自检"，逐条发 `*IDN?`、`SYST:VERS?`、各通道 `VOLT?/CURR?`（负载走 `FUNC?`、`INP?`、`MEAS:VOLT?`），回值和异常写进运行日志。接真机排查问题先点这个。

## 五、命令依据

代码里的每条 SCPI 都对着官方编程手册核对，不是猜的：

| 功能 | 命令 | 出处 |
|---|---|---|
| 远程/本地 | `SYST:REM` / `SYST:LOC` | IT6302 编程指南 · SYSTem:REMote / LOCal |
| 电源选通道 | `INST CH1\|CH2\|CH3` | IT6302 · Chapter10 INSTrument[:SELect] |
| 电源设压/限流 | `VOLT <n>` / `CURR <n>` | IT6302 · Chapter6/7（作用于"当前通道"） |
| 电源通道开关 | `CHAN:OUTP ON\|OFF` | IT6302 · [SOURce:]CHANnel:OUTPut[:STATe]（仅当前通道；`OUTP` 不带参数是全部） |
| 电源回读 | `MEAS:VOLT?` / `MEAS:CURR?` | IT6302 · Chapter9 |
| 负载模式 | `FUNC CURR\|VOLT\|RES\|POW` | IT8500+ 编程指南 · [SOURce:]FUNCtion（`MODE` 等价） |
| 负载设定 | `CURR 1.0` / `VOLT 5` / `RES 10` / `POW 20` | IT8500+ · 各 [SOURce:]Xxx[:LEVel] |
| 负载输入 | `INP ON\|OFF` | IT8500+ · [SOURce:]INPut |
| 负载回读 | `MEAS:VOLT?` / `MEAS:CURR?` / `MEAS:POW?` | IT8500+ · MEASure 子系统 |

手册下载在 `../docs/`（IT6302 Programming Guide、IT8500+ Programming Guide）。

## 六、已知限制

- **未在真机上验证**。命令按手册写，但不同固件版本可能对个别查询（如 `CHAN:OUTP?`、`FUNC?`）返回格式有差异。第一次接真机请先点"通信自检"，有异常把日志发我改。
- 轮询周期 0.8s（界面与最快记录间隔同此量级）。仪器侧用 `MEAS:VOLT? ALL` 等 ALL 查询可把每轮命令从 6 条减到 2 条，进一步提速待做；要更快可改 `FETC?`（读缓存值）。
- `dist/` 的 exe 为旧版本打包产物，落后于当前源码，需重新打包。
- 导出的是内存里缓存的数据（最多约 4.4 小时），程序关掉就没了；需要长时间记录请定期导出。
- IT6302 的 CH1+CH2 串联/并联模式（`OUTP:SER` / `OUTP:PAR`）未做进界面——涉及实际接线，误操作风险高，需要的话在面板上设。
- 桌面版内部用本机回环地址（127.0.0.1，端口随机）通信，外部访问不到；网页模式同理，只监听本机。
